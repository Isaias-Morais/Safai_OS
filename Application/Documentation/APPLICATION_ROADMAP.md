# Application Roadmap

1. Preserve the signed-off architecture; obtain product-owner decisions for the explicitly unresolved business and operational policies before implementing their affected capabilities.
2. Establish pinned application stack, secrets handling, auth, RLS, private storage, audit foundation, and tests.
3. Implement the E002 inference service adapter and authenticated incident-draft path.
4. Implement Citizen reporting/tracking, then Admin review/assignment, then Driver execution/evidence against the same lifecycle.
5. Add verification deadlines, ledger idempotency, notifications, observability, load/security testing, and field pilots.

No dashboard implementation starts before phase 1 prerequisites are approved.
